# abc329-C Count xxx

## 詰まったところ
「長さ i の同じ文字の繰り返しが S に含まれるか」を i を大きい方から全部試した。
26文字 × N 通り × `includes` の O(N) で 26N²。方針は合っていたのに計算量で落ちた。

## 想定解
連続する同じ文字の塊（ランレングス）を1回のスキャンで数える。
長さ L の塊からは 1..L 文字の L 種類が作れるので、答えは「文字ごとの最長の塊」の合計。O(N)。

## なぜそこに気づけなかったか
「存在するか」を毎回探しに行く形になっていた。
探索対象が入力そのものの構造（連続の塊）で決まるときは、探しに行かずに1回のスキャンで構造を取り出す。
