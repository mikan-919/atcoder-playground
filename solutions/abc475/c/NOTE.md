# ABC475 C Walk the Line

## 詰まったところ

隣の短い道を選ぶ貪欲法を考えたが、訪れる区間全体の移動距離へ言い換えられなかった。

## 想定解

訪れる街を、街 S を含む区間 `[l, r]` として全探索する。
S から左右の端までの距離を X、Y とすると、必要な移動距離は `min(2X + Y, X + 2Y)` になる。

## なぜそこに気づけなかったか

道の長さ `A_i` を街の位置のように扱い、隣の選択を繰り返す問題として考えたため。

## 次に見たら思い出すこと

一直線上で訪れた頂点は区間になるため、区間の両端を決めて移動距離を数える。
