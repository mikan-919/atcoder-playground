# abc473-E K-Divisible Subarrays

## 詰まったところ
和が `K` の倍数になる末尾区間を毎回すべて足し直す `O(N^2)` の方法までは作れたが、その存在判定を高速化できなかった。累積和を使うと知っても、同じ余りの再登場を見るところにつながらなかった。

## 想定解
現在の区間内に現れた累積和 modulo `K` を Set に持ち、同じ余りが再登場したら得点を 1 増やして状態をリセットする。最も早く終わる得点区間を選ぶ貪欲なので、残りを最長にできる。

## なぜそこに気づけなかったか
「区間和を累積和の差にする」で止まり、差が `K` の倍数という条件を「両端の累積和の余りが等しい」と言い換えられていなかった。一方、見つけ次第区切る貪欲部分には自力で到達できていた。

## 次に見たら思い出すこと
割り切れる区間は同じ累積和の余りのペア。重ならない区間の最大個数なら、最初の重複で区切って再出発する。
